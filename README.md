# Tableau de bord personnel

Ouvrez `index.html` dans votre navigateur (double-clic ou glisser le fichier dans une fenêtre). Rien à installer.

La page réunit l’agenda du jour, les tâches, les habitudes et les objectifs. Les textes d’exemple se modifient sur place. Tout est enregistré dans ce navigateur : fermer la page ne l’efface pas.

En bas de page, **Exporter mes données en JSON** télécharge une copie de secours. **Importer** la restaure sur cet ordinateur, ou sur un autre.
